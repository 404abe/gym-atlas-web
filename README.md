# About

GymAtlas is a minimalistic, community-driven gym equipment atlas. Search and explore gyms, discover what machines they have, and contribute to the database by adding gyms and equipment.

# Features

- Interactive map to find gyms near you
- Browse and filter gym equipment by brand, type, and series
- Community contributions — add gyms and link equipment
- Equipment and gym ratings
- Favourites system
- Leaderboard for top contributors
- Admin review system for submissions
- User profiles and best-in-class equipment picks
